# Ch. Vignesh - Portfolio Website

A personal portfolio website featuring:
- **Large Left Side Vertical Capsule Bar**: A large, prominent vertical capsule pill (`54px` wide, `380px` tall, `border-radius: 9999px`) fixed on the left edge with frosted glass effect and accent glow, where the bold text **`CH. VIGNESH PORTFOLIO •`** continuously scrolls in a smooth vertical marquee loop.
- **Unified Skill Badges**: **Java** is styled identically to C, Python, and the remaining programming skills without differentiation.
- **Mirrored Border Architecture**:
  - **Left-Side Sections**: **Education** and **Projects** feature prominent accent borders along the **LEFT** edge (`border-left: 4.5px solid var(--accent-thick)`).
  - **Right-Side Sections**: **Technical Skills** and **Certifications** feature prominent accent borders along the **RIGHT** edge (`border-right: 4.5px solid var(--accent-thick)`), creating a balanced, mirrored layout.
- **Navbar Transition**: Full navbar displayed at the beginning on the intro page; on scrolling, it transitions into **only** the top-right floating **Oval Pill Dock** (showing `Education`, `Education — Skills`, `Skills`, etc.) beside the dedicated theme toggle button.
- **Bi-directional Reversible Scroll Animations**: Left and right sections smoothly slide in when scrolling down and smoothly slide back out when scrolling up.
- **Reference Image Contact Layout**: 4 clean rounded cards with top-centered icons, bold uppercase headers, and clean subdetails matching the uploaded reference image.
- **Ultra-Small Custom Cursor on Hover**: Pinpoint 10px hover reduction with accent glow.
- **Vanta.js 3D Animated Dots Background** powered by Three.js (r134).
